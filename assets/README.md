# NEON HAND AI - Assets Directory

This folder stores static multimedia assets used by the AR application:

## Subdirectories:
- `icons/`: Cyberpunk UI icons, cursor textures, badge bitmaps (PNG with alpha channel).
- `sounds/`: Interactive SFX (gesture triggers, UI clicks, audio feedback).
- `models/`: Custom trained models or serialized tflite weight files.

Ensure all image assets are formatted as 32-bit PNGs (RGBA) for clean alpha blending in OpenCV.
