# 🖐️ NEON HAND AI – Real-Time Hand Tracking & Neon AR Visualizer

A real-time Computer Vision application built using Python, OpenCV, and MediaPipe to track hand movements, detect hand landmarks, recognize gestures, and visualize interactive neon-style effects through a webcam.

## 🚀 Project Overview

NEON HAND AI is a computer vision experiment designed to explore real-time human-computer interaction using hand tracking technology. By leveraging MediaPipe's hand landmark detection and OpenCV's image processing capabilities, the application detects and visualizes hand movements with futuristic neon-style graphical effects through a Python GUI.

This project was developed as a one-night experiment to explore the practical implementation of Computer Vision and interactive AI-powered visual experiences.

## ✨ Key Features

- **Real-Time Hand Tracking:** Detects and tracks hand movements through a webcam.
- **21 Hand Landmark Detection:** Identifies key points across the hand for tracking and visualization.
- **Neon Skeleton Visualization:** Renders hand landmarks and connections with neon-style visual effects.
- **Gesture Recognition:** Recognizes hand gestures using tracked landmark information.
- **Interactive Visual Effects:** Creates visually engaging computer vision effects.
- **Webcam Integration:** Uses a standard webcam for real-time interaction.

## 🛠️ Technology Stack

- **Programming Language:** Python
- **Computer Vision:** OpenCV
- **Hand Tracking:** MediaPipe
- **Numerical Processing:** NumPy
- **Interface:** Python GUI

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/vijipavi/neon-hand-ai.git
```

### 2. Navigate to the Project Directory

```bash
cd neon-hand-ai
```

### 3. Install Dependencies

```bash
pip install opencv-python mediapipe numpy
```

### 4. Run the Application

```bash
python main.py
```
